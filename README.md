# 弹幕直播间 · ST-Danmaku

给 SillyTavern / TauriTavern 用的**直播弹幕**扩展。

它不绑任何角色卡：读当前卡绑定的世界书，派一个 AI 去当"直播间观众考古员"，产出一份《观众档案》，
然后每轮正文生成完就自动放出一批弹幕——**每批 15 条、从右往左飞、每条颜色随机且必须是亮色**。

```
正文 → 弹幕     单向。弹幕读最近几轮正文，所以贴着剧情走。
弹幕 → 正文     默认完全没有，正文一个 token 都不多吃。
```

---

## 它长什么样

| 位置 | 说明 |
|---|---|
| **酒馆「扩展」面板里的设置栏** | 展开酒馆的扩展区就能看到「弹幕直播间」一栏：开关、条数、扫描、出一批、状态摘要都在这里，不用去摸悬浮球 |
| **楼层弹幕框** | 每轮正文下面挂一块幕布，弹幕从右往左飞。播完可留一份静态列表往回翻 |
| **悬浮弹幕层** | 飘在界面最上层，可拖动、右下角可拉伸，位置和大小会被记住；只有标题栏和拉伸柄接收鼠标，幕布本身完全穿透，不挡你聊天 |
| **悬浮球** | 右下角一个「弹」字球，点开是七页完整设置面板，位置可拖 |

弹幕颜色不是随便随机的：插件在启动时采样你页面**实际背景的亮度**，然后只从"高饱和 + 高亮度"里取色，
并且用 WCAG 对比度公式筛一遍——**对比度不够的颜色直接丢掉重摇**。所以不管你是深色主题还是亮色主题，
都不会出现看不见的弹幕。

## 核心设计

### 1. 世界观怎么读进来的（不绑卡）

按**当前卡绑定的世界书 + 全局开启的世界书**自动决定读哪些，也支持手动勾选。

世界书规模差异巨大（有的卡 3 条，有的大世界书 600+ 条 / 80 多万字），所以扫描是**预算制三步**：

```
① 索引   只读条目名与字数        几乎不花 token，先摸清"这本书有什么、有多大"
② 取样   在字数预算内挑条目      常量条目（蓝灯）优先，其次是与最近正文相关的
③ 总结   压成有字数上限的档案    "这批观众是谁、用什么词"
```

面板上会如实显示三级数字：`条目总数 / 实际读取条数 / 档案字数`。数字不对就调预算，不用改代码。

**没有任何世界书也照样能用**：这时档案为空，提示词转为"靠正文学着认人认事，不要发明设定"。

### 2. 唯一的内容硬约束

需求里只有一条硬要求：**读起来必须是直播弹幕，不能是别的东西。**
所以提示词里绝大部分篇幅都在干这件事：短句、抢话、@人、刷屏、催更、抬杠、玩梗；
明确的禁止清单：不许旁白、不许总结式长句、不许"接下来让我们看看"的主持人腔、
不许把设定当资料念出来。世界观档案只回答"这批观众是谁、用什么词"，不改变体裁。

### 3. 与剧情的关系

每批弹幕生成前会把最近 N 轮正文（默认 2 轮，可调 0~10）作为"正在直播的内容"喂给弹幕 API。
所以弹幕知道刚发生了什么，会争论、会站队、会押注、会催——**但它们只知道看到的部分**，不读心、不知道未来。

### 4. 正文 token 完全隔离

弹幕是**独立的 API 请求**，从零拼消息数组（只有一条 system + 一条 user），
不经过酒馆的提示词组装，不读角色卡、不读人物设定、不读聊天历史模板。

| 项目 | 是否发生 |
|---|---|
| 弹幕写进正文提示词 | ❌ |
| 弹幕写进聊天记录 `.jsonl` | ❌（只在内存与 localStorage） |
| 弹幕写进你的变量（MVU 等） | ❌ |
| 弹幕被世界书扫描到 | ❌ |
| 弹幕占正文上下文 | ❌ |

**开着弹幕和关掉弹幕，你正文那一轮发给模型的提示词长度完全一样。**

### 5. 直播模式（唯一伸向正文的通道）

一个总开关，默认**关**：

- **关** — 角色完全不知道有弹幕。弹幕只是给你看的"观众视角"。
- **开** — 角色知道自己在被直播。插件用 `setExtensionPrompt()` 写一条**极短**的注入（默认上限 320 字）：
  "此刻有人在直播看着你们，他们刚在说……你可以偶尔有一丝反应，但不要长篇回应观众"。
  这条注入**只存在于内存**，不写进聊天文件、不被世界书扫描、有硬字数上限。

## 安装

### 方式一：跑安装脚本（推荐）

```powershell
# 在本文件夹里
powershell -ExecutionPolicy Bypass -File .\安装.ps1
```

脚本会自动找到 TauriTavern / SillyTavern 的数据目录，把插件复制到 `extensions\third-party\ST-Danmaku\`，
遇到旧版本会先备份。装完 **Ctrl+R 刷新酒馆页面**，右下角就会出现「弹」字球。

### 方式二：手动复制

把整个文件夹复制到：

```
<TauriTavern 数据目录>\extensions\third-party\ST-Danmaku\
```

常见位置：

- TauriTavern：`%APPDATA%\com.tauritavern.client\data\extensions\third-party\`
- SillyTavern：`<SillyTavern 目录>\data\<你的用户名>\extensions\third-party\`

然后刷新页面。想卸载就直接删掉那个文件夹。

## 快速上手

1. 展开酒馆的**扩展面板**，找到「弹幕直播间」那一栏（或者点右下角的「弹」球）
2. 点「扫描世界书」（这一步会调用一次 API，产出观众档案）
3. 可选但强烈建议：到**观众**页点「生成观众名册」——有常驻观众才像直播间
4. 正常聊天，每轮正文生成完就会自动出一批弹幕
5. 想要角色也感知到直播，打开「直播模式」

> 开场白（0 楼）默认不出弹幕：那时还没有剧情，观众没什么可说的。这个限制可以在「风格」页关掉。

## API 配置

两条真实路线，面板里选一条：

### 甲 · 走酒馆后端（默认，推荐）

插件把请求打到酒馆自己的 `/api/backends/chat-completions/generate`，**由酒馆后端去用你已保存的密钥**。

> 为什么必须这样：酒馆 `config.yaml` 里 `allowKeysExposure: false` 时，`/api/secrets/view` 会返回 403，
> 插件根本读不到你的 key。而后端自己 `readSecret`，所以这条路能直接用你已经配好的 key，不用重填。

可选源：`custom` / `openai` / `deepseek` / `makersuite` / `openrouter` / `claude` / `groq` / `mistralai`。
也支持填酒馆的**代理预设名**。模型名留空就用酒馆当前模型。

### 乙 · 直连

自填 `API 地址 + Key + 模型`，浏览器直接发请求。完全独立，但**端点必须允许跨域（CORS）**——
本地 vLLM / LM Studio / Ollama 之类的 OpenAI 兼容端点一般都能开。报跨域错误就换甲路线。

## 面板说明

酒馆扩展面板里的那一栏放的是**最常用的几项**；完整设置在这里（点扩展栏里的「打开完整设置」，或点右下角「弹」球）：

| 页 | 干什么 |
|---|---|
| **总览** | 总开关、直播模式、自动直出、每几轮出一批、每批条数、手动出一批、本地预览（不花 API） |
| **连接** | 两条 API 路线、模型、温度、超时、结构化输出开关、测试连接、拉模型列表 |
| **世界书** | 勾选要读的世界书、三个预算、扫描按钮、三级字数战绩、档案内容可手改 |
| **观众** | 常驻观众数量、每批露脸数、破次元度、观众名册（含立场与口癖、出现次数） |
| **外观** | 弹幕框开关/背景/高度/字号/速度/间隔/透明度、悬浮层开关/透明度/淡出、重置悬浮层位置 |
| **风格** | 读几轮正文、正文预算、历史保留轮数、开场白是否出弹幕、直播注入深度与字数上限、调试开关 |
| **记录** | 最近 N 批弹幕列表，可逐批重播 |

## 自检（开发者）

插件本体零依赖、零构建步骤，改完直接刷新即可。想跑自检需要 Node ≥ 18：

```bash
npm run check   # 语法检查（每个文件都过一遍 node --check）
npm test        # 85 项自检：设置持久化 / 配色对比度 / 各家响应解析 / 脏输出兜底 /
                # 世界书预算制扫描 / 体裁自检 / 剧情关联 / 渲染结构 / 正文隔离 / 注入长度 / 事件调度
npm run verify  # 上面两个一起跑
```

自检里带了一个极简 DOM 替身（`test/mini-dom.js`），所以在没有酒馆的环境里也能把渲染与配色真的跑一遍。

## 兼容性

- **TauriTavern**：开发与自检的目标环境，扩展目录 `%APPDATA%\com.tauritavern.client\data\extensions\third-party\`
- **SillyTavern** 1.12+：只用官方公开接口，未做版本特判
- **不依赖酒馆助手（JS-Slash-Runner）**，也不需要任何其它扩展

用到的酒馆接口（都能在 `scripts/st-context.js` 的导出清单里找到）：
`getContext` / `eventSource` / `eventTypes` / `chat` / `chatMetadata` / `characters` / `characterId` /
`getRequestHeaders` / `loadWorldInfo` / `setExtensionPrompt` / `extensionSettings` / `worldInfoList`。

## 常见问题

**装了没反应？** 先 Ctrl+R 刷新；还不行就完全退出酒馆再启动。打开「风格」页的"输出日志提示"能看到插件自己的报错。

**弹幕和剧情没关系？** 检查「风格」页的"读最近几轮正文"是不是被设成了 0。

**报跨域错误？** 你选的是直连路线，端点没开 CORS。切到甲路线。

**扫描很慢/很贵？** 去「世界书」页把"取样正文上限"调小，或打开"只读条目名（极省）"。面板会先显示这次大约会读多少字。

**弹幕太像正经评论、不像弹幕？** 换个更"放得开"的模型，或把温度调高一点（默认 1.05，可到 1.3）。世界观档案里的"语气与措辞"字段也可以手改，写得更具体一点。

**不想让它自己出？** 「总览」页关掉"自动直出"，就变成只能手动点"出一批"。
